# harulog

하루 기록 앱. 프론트엔드 개발자가 백엔드를 배우기 위해 8주 동안 키우는 서비스.
같은 서비스를 두 스택으로 만들면서, **개념(트랜잭션·커넥션 풀·인덱스·인증 등)과 문법을 분리해서**
이해하는 게 목표. 학습 계획은 `docs/backend-todo_1.md` 참고 (개인 학습 메모라 git에는 안 올림).

## 폴더 구조

```
harulog/
├── python/   FastAPI + PostgreSQL + SQLAlchemy   → python/README.md
└── java/     Spring Boot + PostgreSQL + JPA       → java/README.md
```

각 폴더는 완전히 독립적으로 실행된다. 공통 개념·의사결정은 여기(루트 README)에,
스택별 실행법·세부 설정은 각 폴더의 README에 둔다.

## 프론트엔드와 백엔드는 어떻게 다른가

|             | 프론트엔드                    | 백엔드                         |
| ----------- | ----------------------------- | ------------------------------ |
| 누가 쓰나   | 각자의 브라우저               | 서버 1대                       |
| 데이터      | 화면에 잠깐 떠 있으면 되는 값 | 나중에 다시 봐야 하는 값       |
| 동시에 실행 | 거의 신경 안씀                | 같은 코드가 동시에 여러번 실행 |
| 잘못되면    | 화면이 깨짐                   | 데이터가 깨짐                  |
| 배포        | 파일만 변경                   | DB구조 변경                    |
